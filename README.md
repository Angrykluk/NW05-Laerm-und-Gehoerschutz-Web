# Wie laut ist zu laut?

[Unterrichtspräsentation öffnen](https://angrykluk.github.io/NW05-Laerm-und-Gehoerschutz-Web/)

Eine interaktive 45-Minuten-Stunde für Naturwissenschaften in Klasse 5 mit 14 Folien, Lärmampel, Geräuschkarten, Schreibfeldern, Timer und Aufgaben für Schnelle. Alle Inhalte sind in `index.html` eingebettet.

- Beim Öffnen kann das Mikrofon für die Lärmampel freigegeben werden. Die drei Messungen für Raumruhe, Flüstern und normales Sprechen dauern je zehn Sekunden. Ohne Referenzabgleich bezieht sich die Anzeige auf die gemessene Raumruhe.
- Karten in die Felder ziehen, Karte und Feld nacheinander antippen oder Begriffe direkt eintragen. Unter „Folien“ lassen sich die Einträge für die nächste Klasse löschen.
- Die Seite verarbeitet den Mikrofonpegel lokal. Sie zeichnet kein Audio auf und überträgt weder Ton noch Antworten. Schreibfelder werden im eigenen Browser gespeichert.
